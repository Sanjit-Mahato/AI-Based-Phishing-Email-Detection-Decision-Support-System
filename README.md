# AI-Based Phishing Email Detection & Decision Support System

An intelligent cybersecurity system designed to detect phishing emails and provide explainable decision support using machine learning and natural language processing.

## 🎯 Project Overview
This project aims to protect users and organizations from evolving email-based cyber threats by:
- Analyzing email headers, metadata, text body, and URL links.
- Identifying phishing patterns, spoofing attempts, and social engineering indicators.
- Providing transparent confidence scores, risk levels, and actionable security recommendations.
